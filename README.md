# サロンOS Yurari

小さなサロンのための予約・顧客・売上管理アプリです。
`index.html` 1ファイルだけで動きます(ビルド不要・サーバー不要・どの静的ホスティングでも公開可能)。

## できること

- **今日**: 本日の予約一覧、今月の売上・顧客数のサマリー
- **予約**: 日付ごとの予約の追加・編集・削除、ステータス管理(ご予約 / 来店済み / キャンセル)
- **お客さま**: カルテ(名前・ふりがな・電話・メモ)、来店回数の自動集計、検索
- **メニュー**: 施術メニューと料金・所要時間の管理
- **売上**: 「来店済み」の予約から月間売上・客単価・メニュー別内訳・直近6か月の推移を自動集計
- **設定**: JSONでのデータ書き出し・読み込み、サンプルデータ投入、全削除

## 公開のしかた(GitHub Pages)

1. このリポジトリの **Settings → Pages** を開く
2. 「Build and deployment」の Source を **Deploy from a branch** にする
3. Branch を **main** / **/(root)** にして Save

数分後に **https://chainonjoli.github.io/yurari/** でアプリが開けるようになります。
このURLをサロンのオーナーに渡せば、スマホ・PCのブラウザからそのまま使えます。

## データの保存について

データは使っている端末のブラウザ(localStorage)に保存されます。

- サーバーには何も送信されないため、URLを知っている人同士でもデータは共有されません(各自の端末に各自のデータ)
- 端末の変更・ブラウザのデータ削除で消えるため、**定期的に「設定 → データの書き出し」で控えを保存してください**
- 他の端末へは、書き出したJSONを「データの読み込み」に貼り付けて引っ越せます

## 使いはじめ

1. 公開URL(または `index.html` を直接ブラウザで開く)
2. 「メニュー」→ 施術メニューを登録
3. 「お客さま」→ お客さまを登録
4. 「予約」→ 予約を入れる(来店されたらステータスを「来店済み」に)

操作を試すだけなら「設定 → サンプルを入れる」でデモデータが入ります。
